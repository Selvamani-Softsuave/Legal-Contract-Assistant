## 🔬 Architectural Decisions & Research Branches

1. **ReAct Agent vs Fixed Workflow (Week 7 Choice)**:
   * **Branch**: `feature/week7-agent-loops`
   * **Finding**: Fixed deterministic workflows are faster and cheaper for linear 1-hop clause lookups, but autonomous ReAct agents are mandatory for nested cross-references where a clause refers to a defined term in a separate amendment or schedule.
2. **Hardcoded Tools vs Model Context Protocol (Week 9 Choice)**:
   * **Branch**: `feature/week9-mcp-process`
   * **Finding**: MCP JSON-RPC 2.0 decouples agent prompt maintenance from tool infrastructure. Tools can be added, updated, or removed via external servers without rewriting or deploying the agent codebase.
3. **Single Agent vs Multi-Agent Squad (Week 10 Choice)**:
   * **Branch**: `feature/week-10-multi-agent-race`
   * **Finding**: Multi-agent squad architectures incur a heavy "Context Tax" (1.4x token multiplier, 13.4x cost increase, and 8.9x latency penalty) without increasing factual accuracy on legal contract QA. Standardizing on a Single MCP Agent Host is the optimal production pattern.
4. **Shared Corpus Evaluation & Tuning (Week 12 Choice)**:
   * **Branch**: `feature/shared-corpus-evaluation-tuning` & `feature/week-12-capstone-integration`
   * **Finding**: Amendment precedence hierarchies (such as Northwind Amendment No. 2 overriding Amendment No. 1 and Base MSA) require explicit temporal awareness in the retrieval and prompt layers, eliminating supersession hallucinations.
